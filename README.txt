Features:
1. Works offline after first load.
2. Data is saved locally on the phone/browser.
3. Daily dinner: Veg ₹60, Non-veg ₹100, Not taken.
4. Monthly bill and meal count.
5. Payment/advance tracking.
6. Daily history.
7. Monthly summary and simple chart.
8. Export/import JSON backup.
9. Install as Android-style app from Chrome.
